# Todo App
 A simple Todo Appbuilt with React for learning purposes.

## Features
 - ADD new todos
 - Edit todos
 - Delete todos
 - Manage todos with React state

## Teachnologies
   - React
   - JavaScript
   - Vite
   - CSS

## ABOUT
 This project was created to practice React fundamental, including components , props , state, event handling , map and filter.
